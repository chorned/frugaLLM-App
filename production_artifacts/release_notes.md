# FrugaLLM v0.0.9 Release Notes

### 🚀 Features
- **Dual-Theme System & Visual Redesign:** Implemented a full light/dark dual-theme system featuring custom provider icons, textured peach background, and subtle warm brown palette for nodes and canvas headers.
- **Open-Source Attributions & Licensing (CHO-87):** Added root `THIRDPARTY.md` documenting npm packages and Rust crate licenses, expanded comprehensive ecosystem acknowledgements in `README.md`, and added derivative work notice headers.

### 🐛 Fixes
- **OpenRouter Score Mapping:** Fixed score mapping and provider metric parsing for OpenRouter models.
- **Dark Mode UI Refinements:** Resolved high-contrast borders and text readability edge cases across dialog modals, settings panels, and telemetry widgets in dark theme.

### 🔧 Under the Hood
- **Robust Unit & Integration Test Suite:** Added comprehensive vitest suites for attributions compliance and core frontend modules.
- **Node 24 Compatibility:** Validated documentation, typechecking, and runtime compatibility with Node 24.
- **CI / Release Gate Automation:** Enhanced `push-no-mistakes` verification gate and introduced standardized draft release workflows (`/beta`).
