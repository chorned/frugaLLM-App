# FrugaLLM Cross-Platform Implementation Matrix

This matrix provides a component-by-component comparison of how each subsystem is implemented across macOS, Linux, and Windows in FrugaLLM.

| Subsystem | macOS Implementation | Linux Implementation | Windows Implementation | Cross-Platform Invariant |
|---|---|---|---|---|
| **Binary Subsystem** | Standard Mach-O executable; bundled in `.app` | Standard ELF executable | PE32+ executable; `#![windows_subsystem = "windows"]` in release | Release build must never display a detached CLI console window on Windows. |
| **Hardware / VRAM Profiling** | `sysctl hw.memsize` for RAM; `system_profiler SPDisplaysDataType` on Intel; Unified Memory detection on Apple Silicon (`aarch64`) | `sysinfo` + `nvml-wrapper` for Nvidia discrete GPUs | `sysinfo` + `nvml-wrapper` for Nvidia discrete GPUs | Must gracefully default to system RAM minus 2GB if GPU APIs fail or discrete GPU is absent. |
| **Ollama Binary Discovery** | Checks `/Applications/Ollama.app/Contents/MacOS/Ollama`, `/Applications/Ollama.app/Contents/Resources/ollama`, `/opt/homebrew/bin`, `/usr/local/bin` | Checks `/usr/local/bin/ollama`, `/usr/bin/ollama`, and PATH | Checks `%LOCALAPPDATA%\Programs\Ollama\ollama.exe`, `%ProgramFiles%\Ollama\ollama.exe`, `%ProgramFiles(x86)%\Ollama\ollama.exe`, and PATH | Must never report bare directory (e.g. empty `/Applications/Ollama.app` or empty `Ollama` folder) as installed. |
| **Ollama Headless Install** | `export OLLAMA_NO_START=1 && curl -fsSL https://ollama.com/install.sh \| sh` | `export OLLAMA_NO_START=1 && curl -fsSL https://ollama.com/install.sh \| sh` | Pre-creates `%LOCALAPPDATA%\Ollama\upgraded` marker file, downloads `OllamaSetup.exe`, executes silently with `/VERYSILENT /NORESTART` | Headless installation must not launch GUI dialogs or unmanaged background services. |
| **Agent Binary Extensions** | No extension (`hermes`, `opencode`) | No extension (`hermes`, `opencode`) | Resolves `.cmd`, `.bat`, or `.exe` (`hermes.cmd`, `hermes.exe`, `opencode.exe`) | Batch files on Windows must be executed via `cmd.exe /C "<path>"`. |
| **Agent Version Probing** | `Command::new(bin).arg("--version")` | `Command::new(bin).arg("--version")` | Wrapped with `cmd.exe /C` if `.cmd`/`.bat`; `CommandExt::creation_flags(0x08000000)` | Output parsed through `parse_agent_version` regex without terminal window flashes. |
| **Process Tree Termination** | POSIX signals: `pkill -TERM -P`, `kill -TERM`, `pkill -9`, `kill -9` | POSIX signals: `pkill -TERM -P`, `kill -TERM`, `pkill -9`, `kill -9` | `taskkill /F /T /PID <pid>` and `taskkill /F /T /IM <image>` | Windows `taskkill` stderr must be suppressed to avoid `ERROR: process not found` noise when already terminated. |
| **Background Spawning** | Tokio process spawn with piped/null handles | Tokio process spawn with piped/null handles | Tokio process spawn with `creation_flags(0x08000000)` (`CREATE_NO_WINDOW`) | Background daemons must not steal focus or spawn console windows. |
| **Interactive PTY** | `portable-pty` spawning `bash` with `TERM=xterm-256color` | `portable-pty` spawning `bash` with `TERM=xterm-256color` | `portable-pty` (ConPTY) spawning `powershell.exe -NoProfile -ExecutionPolicy Bypass` | PTY streams must handle non-blocking reads; ConPTY does not emit Unix EOF on slave drop. |
| **Shell PATH Integration** | Idempotent block in `~/.zshrc` (auto-created if missing on macOS), `~/.bashrc`, `~/.profile` + symlinks in `~/.local/bin`, `/usr/local/bin` | Idempotent block in `~/.bashrc`, `~/.profile` + symlinks in `~/.local/bin`, `/usr/local/bin` | User Environment variable in Registry: `[Environment]::SetEnvironmentVariable('Path', ..., 'User')` | Must be 100% reversible via toggling Global CLI Commands in settings. |
| **Credential Keyring** | Apple Keychain (`keyring` crate) | Secret Service API / DBus (`keyring` crate) | Windows Credential Manager (`keyring` crate) | Passwords securely stored per OS credential vault; `.env` fallback strictly for debug assertions. |
| **System File Viewer** | `open -t <path>` fallback | `xdg-open <path>` fallback | `notepad.exe <path>` fallback | Primary method uses `app.opener().open_path(...)`, falling back to platform editor. |
| **Application Autostart** | `tauri_plugin_autostart::MacosLauncher::LaunchAgent` | Standard XDG autostart desktop entry | Windows Registry Run key via Tauri autostart plugin | `--silent` or `--minimized` flag honored across all platforms on boot. |
